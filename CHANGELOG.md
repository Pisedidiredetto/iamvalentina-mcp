# IamValentina MCP connector — changelog

The version here is the one `initialize` reports, `/mcp/manifest.json` shows, and `server.json` publishes.

## 0.2.0 — 2026-11-21

First public listing.

- Streamable-HTTP endpoint `POST /mcp` (JSON-RPC 2.0; protocol versions 2025-06-18, 2025-03-26, 2024-11-05). `GET /mcp` answers 405.
- 39 tools plus `get_agent_scope_info` over tickets, customers and Shopify orders, leads, inventory, and the approval queue. Public catalog at `/mcp/manifest.json`.
- Three levels: `read`, `write_low` (small reversible changes), `write_confirm` (draft replies that the owner approves in IamValentina). No tool sends, approves or deletes.
- OAuth 2.1: RFC 8414 / RFC 9728 discovery, dynamic client registration (public clients), PKCE S256 only, `resource` audience binding, access token 1 h, refresh token 30 d with rotation. Static bearer keys for clients without OAuth.
- Pairing code generated by the owner (password step-up, 15 minutes, single use) required on the consent screen.
- Idempotency keys on write tools (24 h), per-token rate limit, results containing customer text flagged `untrusted`.
